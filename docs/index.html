Everything a basic browser needs

Deliberately written in as little Swing code as possible so the WebViewComponent APIs being demonstrated stand out.

☷

Tabs

New tab, middle-click or ✕ to close. Each tab owns its own WebViewComponent and console buffer. Window title and tab strip follow the active page's <title>.

◁▷

Back / forward / reload

Per-tab navigation history driven by a JS shim that hooks pushState, replaceState and popstate — SPA-aware, not just URL-bar input.

🔍

Smart address bar

Type a URL or a search query. Bare hostnames are auto-https://'d; anything that doesn't look like a URL is forwarded to DuckDuckGo.

★

Bookmarks

Starrable from the toolbar, persisted to ~/.swingwebbrowser/bookmarks.tsv. Saved bookmarks appear under the Bookmarks menu; full management dialog included.

⌚

History

Every navigation is appended (with timestamp) to a TSV log. History → Show History… opens a sortable table — double-click any row to reopen.

>_

Developer console

Collapsible panel captures every console.* call (colorised by level), with a one-line JS eval prompt and one-click access to native DevTools (WebView2 / WebKit inspector).

Built with two libraries

The whole browser is ~1500 lines of Swing. All the heavy lifting — web rendering and cross-platform packaging — is done by two small, focused libraries.

ca.weblite:webview

SwingWebView

A JComponent that embeds a native WebView — WebKit on macOS and Linux, Chromium-based WebView2 on Windows. Native libraries bundled in the jar, one Maven dependency, zero install steps. Drives every tab in this browser.

webliteca.github.io/swingwebview → npm:jdeploy

jDeploy

Packages a Java app into native installers for macOS, Linux, and Windows — bundling the JVM, generating auto-updaters, and publishing through GitHub Releases. Turns mvn package into a one-click app for users who don't have Java installed.

Behind the scenes

Every tab is a SwingWebView

The browser is mostly glue around one method call — WebViewComponent.create() returns the right native WebView for the current platform.

BrowserTab.java 
// Each tab owns its own native WebView.
WebViewComponent wv = WebViewComponent.create();
wv.setDebug(true);

// Inject a JS shim at document-start so SPA nav + title changes
// surface as Java events on the EDT.
wv.addOnBeforeLoad(NAV_SHIM_JS);
wv.addJavascriptCallback("__swb_nav", arg -> handleNavEvent(arg));

// Console panel subscribes to every console.* call from the page.
wv.addConsoleListener((level, message) -> devConsole.append(level, message));

// One-click access to the platform's native inspector
// (WebView2 DevTools on Windows, WebKit Inspector on macOS / Linux).
inspectorButton.addActionListener(e -> wv.openDevTools());

// Address bar — navigation, back / forward / bookmark / history
// replay all flow through this single method.
wv.setUrl("https://duckduckgo.com");

See BrowserTab.java for the full source — under 300 lines.

Build it yourself

Clone, mvn package, run. Requires JDK 21 to build; the resulting jar runs on JDK 8+.

shell 
git clone https://github.com/webliteca/swingwebbrowser
cd swingwebbrowser

# Linux / macOS
./run-linux.sh        # or ./run-mac.sh

# Windows
run-windows.bat

The launcher scripts call mvn package the first time, then java with the built jar plus its dependencies on the classpath.
